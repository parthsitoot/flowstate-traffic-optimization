Signal control

Current road demand

Each road gets a score from cars waiting, expected arrivals, and time since its last green. The highest eligible score gets the next green. Green lasts 10–45 seconds, with a 3-second all-red change.

See the scoring formula

Priority = queue + 0.7 × predicted arrivals + 0.08 × seconds since green. These weights are chosen for this demo.

What do the numbers mean?

Three inputs

Cars that arrived in three completed 10-second periods on one road.

One prediction

An estimate for the next 10 seconds. It can be a decimal because 60 trees are averaged.

Test error

Average difference between predictions and true counts on separate generated examples. It is not a guarantee for one input.

The signal controller uses this forecast alongside current queues and waiting time. This page forecasts arrivals; it does not predict the exact time your car would wait.

Behind the project

How it works.

A generated camera image shows colored cars. Image processing finds their shapes and counts them.

A trained Random Forest estimates cars arriving in the next 10 seconds using three recent counts.

Control

The controller weighs current queues, the forecast, and how long each road has waited for green.

Compare

The same generated arrivals are replayed with fixed, queue-only, and ML-assisted signals.

Learning setup

The Random Forest is the part trained with machine learning. Each of its 60 decision trees learns patterns from generated arrival counts; their predictions are averaged.

Training and test examples come from different generated traffic episodes. The model is fitted on the first model request in each server process.

What is actually machine learning?

The arrival forecaster is learned. Signal selection uses hand-written rules, while the camera uses classical image processing. There is no reinforcement learning or pretrained real-road detector.

Experiment results

“Average waiting per arrival” divides all seconds spent in queues by the number of arriving cars. It includes waiting so far by cars still queued at the end of the run.

Assumptions and next steps

This is one intersection with one car crossing per second during green. There are no turns, pedestrians, travel times, or calibration with real roads. The generated camera demonstration is separate from the signal controller. Future work needs real vehicle detection, calibrated simulation, and safety review.
