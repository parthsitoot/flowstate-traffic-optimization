Learning setup

Training and test sets contain independent generated episodes. Overlapping windows from the same episode never cross the split. The model is trained on the first model request in each server process.

What is actually machine learning?

The arrival forecaster is learned. Signal selection is a designed heuristic, and vision is classical image processing. This project does not use reinforcement learning or a pretrained road object detector.

Experiment results

Delay per arrival = sum of all queue lengths over time ÷ total arrivals. This includes waiting by vehicles still queued at the end, but does not estimate their future waiting time.

Boundaries & next steps

One vehicle/second discharge; one approach green at a time; no turns, pedestrians, travel time, or real road calibration. The CV demonstration is separate from the simulation controller. Next: real video detection and tracking, calibrated traffic simulation, and a safety-reviewed controller.
